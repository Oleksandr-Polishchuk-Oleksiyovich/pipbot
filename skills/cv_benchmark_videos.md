## Як використовувати в тестах

Для автоматичного завантаження відео в кеш (`%TEMP%/pipbot_cv_fixtures`) використовується `gdown`:
```bash
python -m pytest tests/integration/test_desktop_videos.py -v
```
Якщо локального файлу немає на робочому столі, завантажувач автоматично стягує його з Google Диску за ID.
